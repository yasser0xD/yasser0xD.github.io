# Yasser Debihi — Portfolio

Personal portfolio of **Yasser Debihi**, a software developer and Computer Science & Networks graduate based in M'Sila, Algeria.

🌐 **Live:** https://yasserdbh.com

## ✨ Features
- Fully bilingual (English / العربية) with full RTL support
- Light & dark themes, persisted via `localStorage`
- Responsive and accessible: skip link, reduced-motion support, visible keyboard focus, no-JS fallback
- Interactive UI: typing effect, scroll reveals, scrollspy nav, animated hero
- SEO-ready: Open Graph + Twitter cards, JSON-LD (Schema.org `Person`), `sitemap.xml`, `robots.txt`
- Installable (PWA web manifest) — zero build step, pure static HTML/CSS/JS

## 🛠️ Tech Stack
- HTML5, CSS3 (custom design system with CSS variables)
- Vanilla JavaScript (i18n, theming, IntersectionObserver animations, scrollspy)
- Bootstrap 5.3, Font Awesome 6.5, Google Fonts (Inter, Outfit, Tajawal)

## 📁 Structure
```
.
├── index.html          # main page
├── 404.html            # themed not-found page
├── robots.txt
├── sitemap.xml
├── site.webmanifest    # PWA manifest
├── .nojekyll           # serve files as-is on GitHub Pages
├── CNAME               # custom domain (yasserdbh.com)
└── assets/
    ├── styles.css
    ├── script.js
    ├── favicon.svg
    ├── php2.jpeg       # profile photo
    └── cv.pdf          # resume
```

## 🚀 Deployment
Hosted on **GitHub Pages** from the `main` branch. The `CNAME` file maps the custom domain `yasserdbh.com`. Any push to `main` redeploys automatically.
